# Changelog

## 0.4.0 — 2026-11-27

### macOS
- Added built-in in-app updates with silent daily checks, **Check for Updates…** in the menu bar, Ed25519 signature + SHA-256 verification, and atomic update & relaunch.

### Android
- Added built-in in-app updates with silent daily checks, an update banner and **App updates** row, Ed25519 signature + SHA-256 verification, and direct APK installation.

## 0.3.0 — 2026-11-27

### macOS
- Replaced **Open Received Files** with a **Received Files** submenu showing the 10 most recently received files (click to open) followed by **Open in Finder…**.

### Android
- Added quick actions on long-press for received files: **Share**, **Open with**, **Open folder**, and **Delete** (with confirmation and stale notification cleanup).

## 0.2.0 — 2026-11-25

- Added app icons for macOS and Android.
- macOS: enabled Launch at Login by default when installed in Applications.

## 0.1.0 — 2026-11-24

- Initial release: LAN file transfer and clipboard sync between Android and macOS.
